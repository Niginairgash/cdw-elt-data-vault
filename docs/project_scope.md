# Project Scope

## Business Domain
This project is based on the dvdrental platform.  
It is a movie rental service with customers, films, rentals, and staff.

## Business Problem
Currently, data is spread across multiple tables and systems.  
It is difficult to analyze historical changes in rentals and customer behavior.  
Business users need faster and more accurate analytics on rentals, revenue, and customer activity.

## Goals of the Data Warehouse
- Create a single source of truth for rental data  
- Store historical changes in rentals, customers, and films  
- Support analytics for revenue, popular films, and customer behavior  
- Provide reliable data for reporting and business decisions  

## Data Consumers
- Data Analysts — for reporting and analytical insights  
- BI Developers — to create dashboards  
- Product Managers — to analyze film performance and customer trends  
- Management — to support decision-making  

## Analytical Questions
- What is the total revenue for a given time period?  
- Which films are the most popular by number of rentals?  
- What is the average rental duration per film?  
- Which films generate the highest revenue per month?  
- Which films generate no revenue during a given month?

## Scope Boundaries
This project focuses only on rental-related analytics.
Payment processing, inventory management, and marketing data are out of scope.

## Non-Goals
- Real-time analytics
- Machine learning use cases
- Operational reporting
